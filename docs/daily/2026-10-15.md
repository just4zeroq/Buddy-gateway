## 涉及功能

这是 1.0.3 里最大的一块新能力，Telegram 通道从「能用」升级为「可按会话范围
管控 + 原生交互」，并把原来 3000 行级的单文件拆成四个职责清晰的子模块。

### 1. 作用域激活（`group_activation` + 白名单）

- `group_activation`：`always`（默认，群内任何消息都触发）/ `mention`（仅
  @bot 或专属命令）/ `mention_or_reply`（@bot、专属命令或回复 bot 的消息）。
- `allowed_user_ids`：用户白名单，私聊与群聊均生效；命中白名单外的消息在
  **拉取媒体、调用 Agent 之前**即被丢弃（省掉无意义的下载与推理）。
- `allowed_chat_ids`：会话白名单，支持负数（超级群 ID）。
- **命令归属**：`@other_bot` 的命令在任何模式下都拒绝；受限模式下必须已知
  bot 身份（`getMe` 拿到的 id / username）才能判定 mention。
- **匿名发送者**（`sender_chat`，即「以频道身份发言」）无法满足用户白名单，
  直接拒绝——因为它没有可绑定的用户身份。

### 2. 原生交互投递

- 回复引用（`reply_to_message`）、论坛话题隔离（`topic_isolation`）。
- 流式模式 `streaming_mode`（`off` / `auto` / `edit` / `draft`）、状态反应
  `status_reactions`。
- 回调按钮：一次性、与发起者身份绑定的 token，按下即失效；按钮回调不会提升
  权限。
- 编辑消息处理（`edited_messages`，命令类编辑始终拒绝）。
- `audio_as_voice`、`disable_notification`、`protect_content`、`link_preview`、
  `command_menu` 等投递选项。

### 3. 相册（album / `media_group`）

新增 `albums` 开关（默认 **关闭**）：把一条 `media_group` 的多个成员合并成
**一个**入站回合；出站时同类附件用 `sendMediaGroup` 成组发送。详见
[2026-10-16](./2026-10-16.md) 与 [2026-10-17](./2026-10-17.md)。

### 4. 结构拆分

`telegram/channel.py` 拆为 `policy.py`（准入判定）、`interaction.py`（回调
token）、`delivery.py`（请求调度 / 错误脱敏）、`format_html.py`（Markdown→
Telegram HTML + UTF-16 4000 分块）。
